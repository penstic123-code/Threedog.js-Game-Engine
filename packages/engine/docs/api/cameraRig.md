# engine.cameraRig — followCamera(opts?: FollowCameraOptions) / firstPersonCamera(opts?: FirstPersonCameraOptions) / fixedCamera(opts?: FixedCameraOptions) / rtsCamera(opts?: RtsCameraOptions)

Current camera (one of followCamera / firstPersonCamera / fixedCamera / rtsCamera)

- followCamera options `FollowCameraOptions`:
  - `projection?: 'perspective' | 'orthographic'` 'orthographic' draws without perspective (isometric / 2.5D; the wheel then changes size); default 'perspective'
  - `size?: number` With projection 'orthographic': world units of view height, default 20
  - `yaw?: number` Which side of the focus the camera sits on (radians), default 0.8: camera = focus + (sin yaw, cos yaw) × distance, it looks along forward() = -(sin yaw, cos yaw). Behind a character facing f: yaw = f + PI
  - `pitch?: number` Pitch angle (radians), default 0.42. Positive = camera above the look point, looking down: the opposite of firstPersonCamera's pitch
  - `distance?: number` Distance (meters), default 13
  - `minDistance?: number` Zoom range (meters)
  - `maxDistance?: number`
  - `height?: number` How high above the character to look at (meters), default 1.4
  - `smoothing?: number` (experimental) Follow smoothing, default 10
  - `sensitivity?: number` Drag sensitivity, default 1
  - `minPitch?: number` Pitch range (radians), default 0.05 to 1.35. The camera never goes below the look point, so the view cannot look up (a tall building's roof stays out of sight); a negative minPitch looks up (recipe 21 section 4b)
  - `maxPitch?: number` (experimental) Upper pitch limit (looking down), default 1.35 (about 77 degrees, not straight down)
  - `zoomStep?: number` (experimental) Zoom ratio per wheel notch, default 0.1
  - `groundClearance?: number` (experimental) Minimum camera height above the ground (meters), default 1.2
  - `invertY?: boolean` (experimental) Invert vertical
  - `lockPitch?: boolean` Lock the pitch angle (top-down games)
  - `shoulder?: number` Over-the-shoulder offset: meters to the right of the target the camera aims (negative = left shoulder), default 0
  - `pointerLock?: boolean` Click locks the mouse; mouse motion turns the view without dragging (Esc releases), default false
  - `swallowLockClick?: boolean` The press that locks the mouse is not delivered as Mouse0 / a click (default true); false delivers it too
  - `ground?: 'raise' | 'shorten' | 'none' | ((facts) => Vec3Like | null | void)` What happens when the camera would go below the ground.
  - `mouseLook?: boolean` false: the built-in mouse / stick look and wheel zoom are off, the game drives the view with setView() (default true)
  - `hideTargetNear?: number` Hide the followed object from the camera when the camera is closer than this to the look point (meters, 0 = never; default 0.9). The shadow stays
  - `hideLayer?: number` Layer used to hide the followed object (0-31), default 30
  - `pixelSnap?: { pixelsPerMeter, bounds? }` Art-pixel rounding, orthographic only: rounds the camera on screen axes, clamps to bounds there first, and decides the view height (buffer height / pixelsPerMeter), so no size with it. Recipe 62 section 4b
- firstPersonCamera options `FirstPersonCameraOptions`:
  - `height?: number` Eye height above the feet (meters), default 1.6
  - `sensitivity?: number` Mouse sensitivity, default 1
  - `fov?: number | null` Field of view (degrees); unchanged if omitted
  - `headBob?: number` Walking bob amplitude (meters), 0 off, default 0.04
  - `bobFrequency?: number` (experimental) Bobs per meter
  - `hideTarget?: boolean` (experimental) Hide the character itself (its shadow remains), default true
  - `hideLayer?: number` Layer number used for hiding 0–31
  - `pointerLock?: boolean` Click to lock the mouse, default true
  - `swallowLockClick?: boolean` The press that locks the mouse is not delivered as Mouse0 / a click (default true); false delivers it too
  - `yaw?: number` Initial heading (radians)
  - `pitch?: number` Initial look angle (radians), default 0 = level. Positive looks up, negative down: the opposite of followCamera's pitch
  - `minPitch?: number` Look down / up limit (radians), default -1.45 / 1.45
  - `maxPitch?: number` (experimental) 
  - `yawLimits?: number[] | null` (experimental) Turn range left / right [min, max] (radians), unlimited by default
  - `smoothing?: number` (experimental) Smoothing of the camera following the body
  - `invertY?: boolean` (experimental) Invert vertical
- fixedCamera options `FixedCameraOptions` (also includes the fields of Partial<CameraShot>):
  - `pixelSnap?: { pixelsPerMeter, bounds? }` Art-pixel rounding, orthographic only: rounds the camera on screen axes, clamps to bounds there first, and decides the view height (buffer height / pixelsPerMeter), so no size with it. Recipe 62 section 4b
  - `shots?: Record<string, CameraShot>` Shots: name → shot
  - `start?: string | null` Initial shot name
  - `auto?: false | 'nearest'` Automatic switching: false / 'nearest' (pick the one nearest to the player)
  - `autoInterval?: number` (experimental) Check interval for automatic switching (seconds)
  - `hysteresis?: number` How many meters closer a new shot must be to switch (prevents flipping back and forth)
  - `triggerBlend?: number` (experimental) Transition seconds for trigger-zone switches (0 = hard cut)
  - `trackHeight?: number` (experimental) How high above the character a track shot looks (meters)
  - `trackSmoothing?: number` (experimental) Head-follow smoothing
  - `holdDirection?: boolean` (experimental) Keep the direction when switching shots until the direction key is released
  - `ease?: Ease` Transition easing
- rtsCamera options `RtsCameraOptions`:
  - `height?: number` Camera height above the focus (meters), default 30
  - `minHeight?: number` Zoom range (meters)
  - `maxHeight?: number`
  - `pitch?: number` Pitch down angle (radians, π/2 = straight down), default 0.95
  - `yaw?: number` Initial horizontal heading (radians)
  - `panSpeed?: number` (experimental) Pan speed multiplier
  - `dragPan?: boolean` (experimental) Drag with the mouse to pan, default true
  - `edgePan?: boolean` (experimental) Pan at the screen edge, default false
  - `edgeSize?: number` (experimental) Edge width (fraction of the screen)
  - `bounds?: { minX?, maxX?, minZ?, maxZ? } | null` Focus range (meters)
  - `rotate?: boolean` false: no turning. Default true: declares the actions rotateLeft / rotateRight (no keys; presets.bindings.rtsRotate binds Q / R)
  - `rotateSpeed?: number` (experimental) Rotation speed (radians/second)
  - `zoomStep?: number` (experimental) Zoom ratio per wheel notch
  - `smoothing?: number` (experimental) Smoothing
  - `fov?: number | null` Field of view (degrees); unchanged if omitted
  - `followLock?: boolean` (experimental) Manual panning is not allowed while following
  - `start?: PositionLike | null` Initial focus (position)

## Methods and properties
- `cam.follow(obj: Object3D | null, opts?: { distance?, height? })` — Follow someone (called automatically when the player is created), null to cancel. opts temporarily changes distance / height (used while driving), restored when the target changes
- `cam.forward() → DirXZ` — The "forward" direction on the horizontal plane (player movement is relative to it)
- `cam.right() → DirXZ` — The "right" direction on the horizontal plane
- `cam.focusPoint() → Vector3` — Where the world loads around (the followed object's position, else the camera's)
- `cam.screenToGround(ndcX: number, ndcY: number) → Vector3 | null` — Screen coordinates (-1..1, engine.input.pointer.ndcX / ndcY) → the point on the ground under it, null if nothing is hit (every camera kind)
- `cam.update(dt: number, input: Input)` — Update the camera every frame
- `cam.onOverride(on: boolean)` — Called when a cutscene takeover starts / ends
- `cam.onEnter(switched?: boolean)` — Called when this camera is switched in (switched: switched at runtime)
- `cam.onExit()` — Called when this camera is switched out
- Properties:
  - `kind: CameraKind` Current kind (the first argument of engine.setCamera)
  - `target: Object3D | null` The object being followed
  - `pixelSnap?: { grid, error, agrees, bounds } | null` The pixelSnap option at work, or null: grid (give it to pixelSprite), error (last rounding in art pixels), agrees (false: something else set the view height, rounding stopped)
- followCamera only: every item of the options (the options of `followCamera`) can be read and written at runtime, e.g. `engine.cameraRig.yaw = 1.2`, `pitch`
  - `cam.frame(target: Object3D | Vec3Like | null, opts?: { strength?: number })` — Lock-on framing: turn yaw each frame toward "behind the followed object, looking at target"; mouse yaw is ignored meanwhile; null hands yaw back. strength default 6 (1/s)
  - `cam.setView(view: { yaw?, pitch?, distance? })` — Set the view from game code: pitch is clamped to minPitch..maxPitch, distance to the zoom range. Negative pitch looks up. Pair with mouseLook: false to own it every frame
  - `cam.getView() → FollowCameraView` — The current view: angles, wanted / actual arm, look point and 3D look direction
  - `focus: Vector3` Smoothed follow point
  - `lockPitch?: boolean`
  - `avoidOcclusion?: boolean` false: no occlusion handling
  - `framing: { target: Object3D | Vec3Like; strength: number } | null` Lock-on framing set by frame()
  - `arm: number` Actual arm length last frame (after walls and ground), meters
- firstPersonCamera only: every item of the options (the options of `firstPersonCamera`) can be read and written at runtime, e.g. `engine.cameraRig.yaw = 1.2`, `pitch`
  - `cam.lookAt(position: PositionLike)` — Turn toward a world position (Vector3 / object / [x, y, z] / { x, y, z })
  - `eye: Vector3` Eye position
- fixedCamera only: 
  - `cam.add(name: string, shot: CameraShot)` — Add / replace a shot
  - `cam.cut(name: string)` — Cut to a shot immediately
  - `cam.blend(name: string, opts?: { seconds?: number; ease?: Ease }) → Promise<void>` — Transition smoothly to a shot ({ seconds = 1, ease }); the Promise resolves when done
  - `cam.nearest(p: Vector3) → string | null` — Name of the shot nearest to a point
  - `shots: Record<string, any>` All shots. A shot stays where it was placed: for a view that pans at a fixed angle use followCamera({ mouseLook: false }) (recipe 21 section 6)
  - `current: string | null` Current shot name
  - `auto: false | 'nearest'`
  - `autoInterval: number`
  - `hysteresis: number`
  - `triggerBlend: number`
  - `trackHeight: number`
  - `trackSmoothing: number`
  - `holdDirection: boolean`
  - `ease: Ease`
- rtsCamera only: every item of the options (the options of `rtsCamera`) can be read and written at runtime, e.g. `engine.cameraRig.yaw = 1.2`, `pitch`
  - `cam.moveTo(position: PositionLike, opts?: { instant?: boolean })` — Move the view to position (instant: true skips smoothing)
  - `following: boolean` Is it following target
  - `focus: Vector3` Focus (on the ground)
  - `rotate: boolean` Can it rotate

## Data structures
- **CameraShot** Fixed shot
  - `position: Vec3Like` Camera position
  - `lookAt?: Vec3Like` Fixed point to look at (if omitted, it turns its head with the player)
  - `track?: boolean` Turn its head with the player
  - `fov?: number` Field of view (degrees)
  - `at?: Vec3Like` Position used to judge the "nearest shot", defaults to position
  - `trackHeight?: number` How high above the character to look at (meters)
  - `projection?: 'perspective' | 'orthographic'` 'orthographic' draws this shot without perspective (isometric / 2.5D); default 'perspective'
  - `size?: number` With projection 'orthographic' (required there): world units of view height; the width follows the aspect

# engine.events (Events) — engine.events: the event bus; modules "shout" and whoever cares listens

- `events.traceFocus(id: string | null)` — Verbose trace for one object (needs traceSize > 0): perception queries and state checks that name `obj` === id are recorded in full (misses too), the rest of the world only records what changed. null clears. For "why did this guard not see me": traceFocus('guard-1'), play, then read trace('sight'). Example: `engine.events.traceSize = 300; engine.events.traceFocus('guard-1');`
- `events.note(name: string, info?: { code?, obj?, data?, verbose?, parent? }) → string | null` — Add one entry to the cause trace (no-op while traceSize is 0; check `events.traceSize > 0` first to skip building info). Returns its parent id (`ev:<n>`) to pass as info.parent of follow-ups, or null. info: code (failure code), obj (world record id it is about), data (small plain values), verbose (true = only recorded while traceFocus(obj)), parent (default: the event or op running now). The engine notes failed ops (`op:<name>`), collision.lineClear (`sight`) and NPC state changes (`npc:state`); a game's behaviors can note their own, e.g. 'npc:mode' patrol -> investigate. Example: `if (e.events.traceSize > 0) e.events.note('npc:mode', { obj: rec.id, data: { from: 'patrol', to: 'investigate' } });`
- `events.trace(name?: string) → { id, tick, name, parent, chain, code?, … }[]` — Cause chains (needs traceSize > 0): each emitted event is recorded with parent = the event (`ev:<id>`) or op (`op:<name>#<seq>`) whose handler emitted it, null when it came from outside any. chain lists the causes from the nearest to the root (as far as the ring still holds). For "why did this fire". Example: `engine.events.traceSize = 200; engine.ops.run('shop.buy', { item: 'bread' }); engine.events.trace('item:add').at(-1).chain;   // ['op:shop.buy#12']`
- `events.recent(name?: string) → { tick, name, data }[]` — Recent events (old -> new); with name, only that kind: { tick = which fixed step, name, data = summary (simple values only; objects become '…') }. For "why did it not fire", first check whether it happened at all. Example: `engine.events.recent('item:add');`
- `events.on(name: K, fn: (args) => void) → Handle` — Listen to an event; returns a handle { remove() }. Example: `const h = engine.events.on('item:add', ({ id, count }) => console.log(id, count)); h.remove();`
- `events.once(name: K, fn: (args) => void) → Handle` — Listen once; returns a handle { remove() } (can be removed before it fires)
- `events.emit(name: K, ...args: EventArgs<K & string>)` — Emit an event. Example: `engine.events.emit('item:add', { id: 'fish', count: 1 });`
- Properties:
  - `historySize: number` How many history entries to keep, default 200; 0 records nothing
  - `traceSize: number` Cause trace ring size, default 0 = off (no cost). Set e.g. 200 in dev to record which event or op caused which follow-up event; read with trace()

## Event table (engine.events.on(name, (args…) => …), the [] lists the callback arguments)
- `engine:ready` [] Loading finished; the world is playable
- `audio:ready` [] Audio can play (after the player's first click / key press)
- `i18n:change` [locale: string] UI language changed; the argument is the new language
- `input:rebind` [{ action: string | null; keys: string[] | null }] Key bindings changed; action null means everything was reset to defaults
- `input:context` [{ stack: string[] }] 
- `save:written` [slot: string] Save written to disk; the argument is the slot name (not emitted when the write fails, a toast is shown instead)
- `save:imported` [slot: string] Restore from a save file (saves.importFile) finished; the argument is the slot name. Attachments in the file (such as photos) are written to storage too
- `save:loaded` [slot: string] A save was loaded onto the running playthrough (saves.load / session.load); the argument is the slot name
- `ui:open` [id: string] A window was opened (the argument is the window id, e.g. 'inventory')
- `ui:close` [id: string] A window was closed
- `settings:shadows` [on: boolean] Shadows were toggled
- `settings:change` [values: Record<string, any>] A value in the settings menu changed (the argument is all setting values)
- `post:add` [name: string] A post effect was added (its name)
- `water:add` [body: WaterBody] A water body was added
- `water:remove` [body: WaterBody] A water body was removed
- `day:start` [day: number] A new day (the argument is the day number, starting at 1; needs the calendar module)
- `season:change` [season: string] Season changed (the argument is the season name, e.g. 'autumn')
- `mod:end` [{ target: string; owner: string; id: string | null }] A mod with `for` ran out (engine.mod(target, { owner, for })): target is the quantity's name, id the record for per-record ones
- `time:skip` [{ seconds: number }] engine.skip jumped game time forward (seconds = calendar seconds skipped); timers and world catch-up already ran
- `weather:lightning` [] Lightning strike (weather module)
- `weather:change` [change: { from: string; to: string }] engine.weather.set switched to another weather name (once, when the blend starts; setting the same name again does not fire)
- `camera:shot` [CameraShotEvent] The fixed-shot camera switched shots
- `camera:change` [{ kind: string; previous: string }] engine.setCamera switched the camera kind; settings that belong to the camera (sensitivity, invert Y, field of view) are re-applied on it
- `character:jump` [{ character: Character; air: boolean; index: number }] A character jumped
- `character:launch` [{ character: Character; speed: number; owner: string }] 
- `link:enter` [{ id: string; character: Character; crossing: LinkCrossing }] (experimental) A walker reached a nav link. Set crossing.seconds here to say how long it takes
- `link:exit` [{ id: string; character: Character | null; crossing: LinkCrossing }] (experimental) A crossing ended: landed, or cut short (npc.placeAt, walk.remove()). character is null for an NPC that went out of range mid-crossing
- `character:fall` [{ character: Character; safe: Vector3 | null }] 
- `character:model` [{ character: Character; model: Object3D }] A character's model named by asset finished loading and replaced the placeholder body (same root; anim is now set)
- `character:step` [{ character: Character }] A foot of a walking character came down; character.groundType() is what it stepped on
- `character:land` [{ character: Character; impact: number }] A character landed; impact is the landing speed (m/s), the larger the harder the fall
- `character:water` [{ character: Character; in: boolean; mode: string; depth: number }] A character went into or out of deep water (water option): in true on entering, mode what the water option did there ('swim' / 'block' / 'wade', or what the function returned)
- `dialogue:start` [speaker: string] Dialogue started; the argument is the dialogue script name
- `dialogue:line` [{ script: string; node: string; speaker: string; text: string; data:… A dialogue line started (after its do ran): data is the node's own fields (portrait, voice...), {} when none. Use it for voice, portraits, camera shots without replacing the UI part
- `dialogue:bubble` [{ speaker: string; text: string; at: any }] A bubble line started showing (the bubble channel: lines over their speakers while play goes on); at is what it is attached to, null = a screen line
- `dialogue:end` [speaker: string] Dialogue ended; the argument is the dialogue script name
- `item:add` [ItemEvent] An item was added to a container (any bag or chest: container names it, actor says who did it)
- `item:remove` [ItemEvent] An item was removed from a container (container names it, actor says who did it)
- `pickup:take` [PickupEvent] A pickup was taken off the ground (pickup = world id, item = its item id or null for a give function, actor = who took it)
- `interaction:hold` [{ id: string; action: string; seconds: number }] A hold interaction started (the key went down on it); seconds is its hold
- `interaction:interrupt` [{ id: string; action: string; reason: string; progress: number }] A hold interaction stopped before it completed: 'released' / 'tooFar' / 'disabled' / 'removed' / 'inputLocked'
- `item:use` [ItemUseEvent] An item was used through the inventory.use op (after use ran)
- `quest:start` [{ id: string }] A quest started
- `quest:step` [{ id: string; step: number }] A quest moved to the next step; step is the new step index (starting at 0)
- `quest:done` [{ id: string }] A quest completed
- `quest:part` [{ id: string; step: number; part: number }] A part of a parallel quest step was met; step and part are indexes (starting at 0)
- `quest:fail` [{ id: string }] A quest failed (its fail condition held); quests.start(id) may begin it again
- `quest:unpaid` [{ id: string; code: string; failed: { word: string; code: string; fa… A finished quest's reward was not given. failed: each word that failed; owed: the items the quest still owes, null when none or when onUnpaid took it
- `content:failed` [{ code: string; failed: { word: string; code: string; facts: any }[]… A content effect word failed ({ give } in a full bag, { op } refused), wherever it ran: a dialogue do, a trigger, a reward, content.run. actor: whose effect it was
- `photo:taken` [PhotoShot] A photo was taken
- `photo:denied` [{ reason: string }] The photo key was pressed but the op photo.take was refused (reason from photo.canTake(), 'denied' when it returned false)
- `trigger:enter` [TriggerEvent] Entered a trigger zone
- `trigger:exit` [TriggerEvent] Left a trigger zone
- `level:loading` [LevelLoadingEvent] Level finished loading
- `level:loaded` [LevelLoadedEvent] 
- `level:unloaded` [LevelUnloadedEvent] 
- `level:playable` [LevelPlayableEvent] 
- `level:failed` [LevelFailedEvent] 
- `timeline:start` [{ id: number }] A cutscene started
- `timeline:end` [{ id: number; ending: 'finished' | 'skipped' | 'dropped' | 'failed';… A cutscene ended; ending says how, error why it failed
- `template:stage` [TemplateStageEvent] A content template instance entered a new stage by growing (templates with stages)
- `ground:change` [{ x0: number; z0: number; x1: number; z1: number }] The ground's shape or type changed in this world-space box (engine.terrain.edit): cached ground samples (path rasters) inside it are stale
- `rigid:rebuilt` [{ world: any; player: any; bodies: Record<string, any> }] rigid: newGame / a load rebuilt the physics world (a fresh page for physics) and the engine's bodies are back (entry.body is the rebuilt Rapier body; bodies maps the ids given to addBox / addBall / addHull / addWheeled). The old world's joints were freed with it: re-create the game's joints here (recipes/11-vehicles.md, Joints). Not emitted while a vehicle exists (the world is kept then, joints included)
- `terrain:void` [{ who: any; position: { x: number; y: number; z: number } }] terrain({ shape }): the player or a moving rigid body dropped below engine.terrain.voidY (once per fall). The engine does not respawn: the game decides
- `terrain:chunkFailed` [{ cx: number; cz: number; error: any }] A terrain chunk job failed every try (usually the game's height / groundType / placement rule throws there): the chunk stays empty and the error is reported. engine.terrain.retry() sends failed chunks again
- `vegetation:remove` [VegetationRemoveEvent] A vegetation instance was chopped / removed
- `vegetation:restore` [VegetationRemoveEvent] A vegetation instance was restored
- `music:change` [MusicChangeEvent] Background music changed track (null means silence)
- `music:stinger` [{ name: string; played: boolean }] A stinger was played
- `state:applied` [StateParams] Scenario parameters were applied (URL parameters or engine.applyState)
- `state:placed` [{ x: number; z: number }] A scenario (at, pos) moved the player: a camera or view that eases jumps there
- `anim:end` [{ root: Object3D; state: string }] A one-shot action of the animation state machine finished
- `world:add` [{ id: string; kind: string }] A record was added to world
- `world:change` [{ id: string; kind: string; keys: string[] }] world.set changed fields (keys lists which)
- `world:remove` [{ id: string; kind: string }] A record was removed from world
- `world:load` [{ count: number }] world finished loading a save (the data is now the save's; caches holding a rec object should refresh on this, count is the record count after loading)
- `net:join` [{ peer: number; actor: string }] Host (net): a peer connected; actor is its world record / container id
- `net:leave` [{ peer: number; actor: string }] Host (net): a peer disconnected (its bag stays; a reconnect with its key gets the same actor)
- `net:open` [{}] Client (net): connected to the host (the first snapshot follows)
- `net:close` [{}] Client (net): connection lost
- `net:sync` [{ tick: number; full: boolean }] Client (net): host state applied (full: a whole snapshot, else a diff); redraw UI from state here
- `net:result` [{ seq: number; name: string; ok: boolean; code: string | null; value… Client (net): the host's answer to an op request (seq from ops.run's return value; tick is the host's), sent after the state it caused
- `engine:error` [EngineError] A gameplay error: in development / testing gameplay is frozen; a release build keeps running and sends it once per site (engine.error holds the first; error severity levels, see engine.error)
- `module:disabled` [{ name: string; message: string }] A picture or ui module errored and was disabled (the game continues)
- `module:restored` [{ modules: any[] }] 
- `op:rolledBack` [{ op: string; parts: number }] An atomic op failed and its parts were put back (its own events already went out and stay): read derived state again. Not sent for a load's rollback (that ends in state:replaced)
- `vehicle:enter` [{ character: Character; vehicle: Rideable }] A character boarded a vehicle
- `vehicle:exit` [{ character: Character; vehicle: Rideable }] A character exited a vehicle
- `flow:change` [{ from: string; to: string }] Game flow state changed
- `flow:transition` [{ phase: 'start' | 'end' }] Scene transition: phase 'start' begins fading to black, 'end' finishes fading back in
- `session:end` [] A playthrough ends (engine.session.newGame / load / quit), before the reset
- `session:start` [{ kind: 'new' | 'load'; slot?: string }] A playthrough started from a clean slate: kind 'new' (newGame) or 'load' (session.load, with the slot)
- `session:failed` [{ kind: 'new' | 'load' | 'quit'; slot?: string }] newGame / session.load failed (a save part's load() threw) and the game was rolled back: the old playthrough goes on, no session:start
- `page:blur` [{ focused: boolean; visible: boolean }] The page went away: the window lost focus or the tab was hidden (engine.page)
- `page:focus` [{ focused: boolean; visible: boolean }] The page came back: focused and visible again
- `page:pointerlock` [{ locked: boolean }] The mouse lock on the canvas started or ended (Esc, alt-tab); cameras with pointerLock lock again on the next click
- `page:contextlost` [] The WebGL context was lost: gameplay waits and the player sees a message
- `page:contextrestored` [] The WebGL context is back: gameplay resumes
- Other names work too (the game's own events, such as 'door:open'), their arguments are just not checked
